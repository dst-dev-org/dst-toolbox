# DST Toolbox 工程设计

最后更新：2026-10-25。工具用于可重建提取、有限定位与校验；现有功能暂时冻结，仅按明确任务补充必要工具，任务状态只在 [PLAN](../PLAN.md) 维护。

## 所有权与输入

本仓维护 Rust／Full Moon 核心、Schema、Python 工具、版本锁、原字节 fixtures、fork pin 及工程验收。用户级配置或显式参数定位知识／源码；不以 checkout 父目录推算。页面格式／标签／大小由所安装知识 Skill 的 write-format.md 提供，生产校验通过 --format 消费，不复制一份规范。

知识页与内容队列在知识仓；正式 reviews／注解／覆盖在独立 lsp-dst fork；轻量路径／源码准备 helper 和共享日志规则由知识 Skill 维护，现有同步工具更新开发 Skill 副本及哈希。日志归档由调用方工作流执行，不新增运行环境依赖；工具运行不自动生成共享知识或修改正式来源。

知识分类兼容 component／prefab／stategraph／api／mechanism／cookbook；mechanism 对应 reference/mechanisms，CLI 筛选共用校验器映射，缓存 inventory 与读取沿用现有实现。Prefab 关系表中的跨分类链接不计其他分类叶级登记，章节工具不跟读目标页；新增类别无正式页时不创建导航或重建正式缓存。此为 2026-10-14 的必要兼容同步，不扩 AST／Schema／类型核验能力。

## 处理层与限制

源码 → 内部 AST → 精简 facts／manifest／覆盖报告 → 有限源码索引。类型候选＋实际源码／必要宿主／消费者 → 正式逐项 reviews → 已核验合并与 LuaCATS。Wiki Markdown／人工导航 → 格式检查 → 可选缓存／候选／章节输出。三条路线分别使用，不要求普通查询走完整流水线。

AST 不默认落盘；facts／索引放知识根 output 并忽略。版本、哈希与生产者／契约不符须拒用或复查；resolved／unresolved／ambiguous 是有限解析状态，不证明运行调用图、对象类型或硬依赖。无命中不证明无实现，partial／failed／截断保留上下文。

具体契约、环境、索引和接口要求按任务读 references，不在本设计重复字段或工具命令。源码行为、结构／LuaLS 检查和游戏运行是不同证据；局部类型修订不能扩为整库准确。

页面／导航、源码引用与单例语法检查的参数／输出归 [Wiki 校验工具](../references/wiki-validation.md)，哈希缓存、清单与 record 细节归 [源码哈希基线工具](../references/source-baseline.md)，迁移预览仍归其既有说明。README 保留命令导航；Skill 只保留选择、常用调用与结果判断，不维护工具行为副本，工程专项也不进入普通写页的读取路径。

源码知识页的可选 size_class 由格式文件的独立分档表驱动，页面校验和 Wiki 索引构建共用解析结果；未标注页面保留标准预算，导航与 cookbook 不接受此覆盖。工具不从源码文件长度猜页面复杂度，档位合理性由知识写作流程审阅。章节查询仍按既有输出预算读取，不随页面写作上限提高默认输出量；现有页面、缓存格式与正式类型契约不需迁移。

独立源码链接检查由 `validate_source_links.py` 按用户请求补充，只用标准库，不接入普通查询或缓存构建的默认链。它按知识页链接的实际路径核对 Lua 文件可读与行号区间，起点空行／结构行、终点空行及 raw 外链接仅警告并附有限上下文；正常终点 end 不增警告，不自动纠正引用或映射快照。HTML 注释和代码过滤保留 Wiki 物理行号，缩进代码不盲目跳过，Markdown 子集的未覆盖与可能误扫范围显式记录。源码和页面只读，问题详情和按页汇总均有限且省略可见；current 的 BUILD.txt 只作背景记录，不代表历史引用版本或匹配通过。版本／哈希是否匹配、引用是否支撑结论仍由审阅确认；原 `validate_page.py` 的元数据／导航职责与 facts 字节锚点校验不变，未扩 AST／Schema／类型流水线。

源码哈希基线检查由 `validate_source_hashes.py` 提供，只用标准库，仅由版本维护、明确来源漂移检查或基线建立／刷新任务调用；Skill 与工具均不把它挂接到普通查询或会话首次读写。基线随知识仓进 Git，显式全库 check 可写 `output/` 缓存；缓存绑定实际源码根、BUILD、快照指纹、知识页集合／内容和清单，版本维护的强制检查按请求范围执行。普通查询不触发哈希缓存写入。

基线按页维护，单页复核只刷新该页；缺源码页保留旧基线，归档页留原路径并可局部移除基线，清单损坏禁止局部刷新，格式错误阻止写入。全量重建须显式执行且会覆盖所有未复核页基线。引用路径按快照大小写精确匹配，宽容文件系统上的大小写漂移单列 `case_mismatch`，record 拒绝把错误大小写写进清单；页 sources 变更单列并不计入失配率，check 报告附完整受影响页队列（每页各类计数）作为版本维护工作清单。哈希检测不替代源码语义审阅或游戏验证；调用、范围与错误处理见 [源码哈希基线](../README.md#源码哈希基线)。

## 验证与演进

版本修补新增只读 `plan_source_link_updates.py`：对完整相同、区间外上下文充分且唯一的引用规划行号，不把唯一片段当成函数身份；上下文识别排除 Lua 行／长块注释及字符串正文。输出有限 JSON 和支持格式的相对知识根补丁，CRLF 等格式受限页只给建议与 review，不自动改写。来源文件对在单次执行内复用读取／匹配结果，变更／歧义／旧错误交回定向复查。更新条目与影响判断在知识仓／Skill，机械匹配边界只在[工具说明](../references/source-link-migration.md)维护，不扩 AST、依赖分析或自动语义迁移。

变更按影响运行既有针对性检查，原字节输入保留；稳定基线不反复执行大规模提取。自动语义迁移未实现；仅真实阻塞触发修复，后续增强要有检索／维护收益证据。当前命令见 [README](../README.md)，历史范围见 [报告说明](reports/README.md)。
